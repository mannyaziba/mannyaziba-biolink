Fix list
Signup — Feedback. No loading state after form submission. The interface goes silent on click. Add a spinner immediately and a clear success confirmation within two seconds.
Dashboard — Structure. Every element competes equally for attention. The eye has nowhere to land first. Establish Receive Money as the primary action with 2–3× the visual weight.
Dashboard — Readability. Balance figures lack explicit currency labels. Users must infer what each number represents. Label every balance with its currency directly.
